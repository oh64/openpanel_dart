# Changelog

## 0.1.3

- Follow openpanel_dart versioning

## 0.1.2

- Initial release of the Flutter integration package, extracted from the former monolithic `openpanel_dart`:
  - `OpenpanelRouteObserver`, `OpenpanelReferrerObserver` and `OpenpanelLifecycleObserver`.
  - `SharedPreferencesStore` (a `KeyValueStore` backed by `shared_preferences`).
  - `FlutterDeviceContext` backed by `device_info_plus` / `package_info_plus`.
  - `initOpenpanelFlutter` convenience initialiser.
  - Re-exports the whole pure Dart `openpanel_dart` API.
